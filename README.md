# 🛍️ Fashion E-Commerce Website

## 📌 Project Overview
This ICT project is a multi-page fashion e-commerce website developed using **HTML, CSS, and JavaScript**.  
The website is designed to provide users with an attractive and user-friendly online shopping experience for clothing and fashion accessories.

The project contains different sections for men, women, kids, and accessories, allowing users to easily browse products according to their interests.

---

## ✨ Features
- Responsive and attractive website design
- Separate pages for different product categories
- Easy navigation between pages
- Product images and descriptions
- Stylish UI with modern layout
- Fashion accessories section
- Organized structure using HTML, CSS, and JavaScript

---

## 📂 Website Pages

### 🏠 Home Page
The homepage acts as the main landing page of the website.  
It provides navigation links to all other sections and displays featured fashion products.

### 👨 Men Page
Contains fashion products and clothing items for men including hoodies, jeans, casual wear, and more.

### 👩 Women Page
Displays women’s fashion products with stylish designs and trendy outfits.

### 👧 Kids Page
Includes a collection of kids’ clothing and fashion items.

### 🎒 Accessories Page
Shows different fashion accessories such as bags, hats, perfumes, and other items.

---

## 🛠️ Technologies Used
- **HTML5** → Structure of webpages
- **CSS3** → Styling and layout design
- **JavaScript** → Interactive elements and functionality
- **Font Awesome** → Icons used in the website

## 🚀 How to Run the Project
1. Download or clone the project folder
2. Open the folder in VS Code or any editor
3. Run `index.html` in your browser
4. Navigate through different pages using the menu
